## Deskripsi

Proyek ini berisi tugas praktikum Desain Web tentang pembuatan form HTML dan styling dengan CSS.

## Isi Proyek

| File           | Keterangan                                              |
|----------------|---------------------------------------------------------|
| `kursus.html`  | Form pendaftaran kursus (tugas individu)                |
| `style.css`    | Styling untuk tampilan form                             |

## Ketentuan Tugas Individu

- Minimal lima tipe input: `text`, `email`, `tel`, `date`, `radio`, dan `checkbox`
- Tiga jenis button: `submit`, `reset`, dan `button`
- Setiap kontrol form memiliki `label` yang terhubung melalui atribut `for` dan `id`

## Cara Menjalankan

1. Pastikan `kursus.html` dan `style.css` berada dalam satu folder.
2. Buka `kursus.html` menggunakan browser.
